蔡格尼克 ep.1 —— Yunxi 配音一键包(Mac 版)

台词不用再找了:lines.txt 里 28 句已从成片反推校对填好。

你只需要三步:
1. 把整个 yunxi-voice-pack 文件夹放到你的 Mac 上
2. 双击「一键配音-Mac.command」(第一次会自动建环境+装 edge-tts,需要联网,家里网络就行)
3. 跑完后把生成的 out 文件夹发回给小噜噜

说明:
- 声音是微软 Edge 的 zh-CN-YunxiNeural(云希男声),免费,不用账号。
- 必须在家里网络跑:微软会封云服务器 IP,所以这一步没法在小噜噜那边做;
  你 Windows 电脑和 Mac 都能跑,哪台顺手用哪台(Windows 用原来的 .bat)。
- 中途失败没关系:重新双击会断点续跑,已生成的句子不会重做。
- 生成的音频按句编号(001.mp3、002.mp3……),小噜噜拿到后负责
  对齐时间、替换进成片,你不用管后面的事。而且现在无人声版已经有了,
  新配音也可以直接铺在无人声版上,不一定要重渲染。

双击时可能遇到的小情况:
- 提示"无法打开,因为来自身份不明的开发者":
  右键点这个 .command 文件 → 选「打开」→ 再点「打开」,只需第一次这样。
- 提示没有 Python / 弹出苹果命令行工具安装窗:
  先把那个装完,或者去 python.org 装最新版 Python,再双击一次。
- 双击完全没反应(权限丢了):
  打开「终端」,把下面这行粘进去回车,再双击一次:
  chmod +x ~/Downloads/yunxi-voice-pack/一键配音-Mac.command
  (如果文件夹不在 Downloads,把路径换成实际位置。)
